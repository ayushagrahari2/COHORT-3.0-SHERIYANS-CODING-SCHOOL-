# Lombok Landing Page

A clean, responsive landing page built with HTML and CSS to showcase a holistic health theme called "LOMBOK." The design includes a full-screen hero section, article previews, an about section, a newsletter signup, and footer navigation.

## 📋 Project Overview

This project is a CSS assignment focusing on static page layout and visual styling. It demonstrates the use of background imagery, flex layout, responsive section structure, and simple UI components.

## ✨ Features

- Full-screen hero banner with background image
- Header navigation and branded logo text
- Article card preview section with image tiles
- About section with split image and content layout
- Newsletter subscribe section with input and button
- Footer navigation bar
- Clean typography and spacing

## 🛠 Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```
04-Assignment-5/
├── index.html    # Main HTML page
├── style.css     # Styling for page layout and visual design
└── README.md     # Project documentation
```

## 🚀 How to View

1. Open the `index.html` file in a web browser.
2. The page will render as a static site without any additional setup.
3. To edit appearance, update `style.css`.

## 💡 Notes

- The page is designed for desktop view, with large hero typography and section spacing.
- Image cards and layout are organized using flexbox.
- The subscribe section is a static UI form element and does not submit data.

## ✍️ Customization Ideas

- Add hover states for buttons and cards.
- Improve responsiveness with media queries for tablets and mobile.
- Replace placeholder links with anchor navigation.
- Add form validation to the newsletter input.
